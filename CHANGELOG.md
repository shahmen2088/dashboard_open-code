# Changelog

## 0.2.0

- Refactored the V1 plugin into testable core, storage, server, usage, models, and UI modules.
- Added deduplicated local usage ledger, token aggregation, reported-cost provenance, and CSV export.
- Added provider/model catalog with local cache and model metadata normalization.
- Added confirmed session model switching with SDK verification and safe fallback command.
- Added local budgets, settings schema 2 migration, journal API, dashboard aggregates, and default-model preview/apply.
- Added request-token, same-origin, body-size, CSP, and security-header protections for the local API.
- Added Windows-friendly build, installable bundle, fixtures, integration tests, security tests, and unit tests.
